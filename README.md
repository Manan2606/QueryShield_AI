# QueryShield AI

QueryShield AI is a governed Text-to-SQL analytics platform for BigQuery.

The goal is to let users upload CSV datasets, ask natural-language questions, generate SQL using Gemini, validate generated SQL for safety, estimate BigQuery cost using dry run, execute only approved queries, show results, and save query history and audit logs.

## Phase-1 Goal

Phase 1 will eventually include user authentication, CSV upload, BigQuery loading, dataset schema storage, natural-language questions, Gemini SQL generation, SQL safety validation, cost estimation, approved query execution, result display, and query history.

## Current Step 2 Scope

This repository currently contains the project foundation, FastAPI backend skeleton, and database foundation:

- Monorepo structure
- FastAPI app setup
- Environment configuration setup
- SQLAlchemy database connection scaffolding
- SQLAlchemy models for users and audit logs
- Alembic migration setup
- Health endpoint
- Database health endpoint
- Backend dependency list
- Environment example file
- Frontend placeholder folder

Authentication, BigQuery, Gemini, CSV upload, SQL validation, and frontend implementation are intentionally not included yet.

## Local Backend Setup

Use the backend virtual environment commands below. Prefer `python -m uvicorn` and `python -m alembic` so PowerShell uses the active environment instead of a global Python install.

```bash
cd backend
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

On Windows:

```powershell
cd backend
py -3.11 -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

If `uvicorn app.main:app --reload` fails with a SQLAlchemy error from a Python 3.13 path, stop the server and rerun it with the activated Python 3.11 virtual environment command:

```powershell
python -m uvicorn app.main:app --reload
```

Run database migrations:

```bash
cd backend
python -m alembic upgrade head
```

Create a future autogenerated migration only after model changes:

```bash
cd backend
python -m alembic revision --autogenerate -m "describe migration"
```

Create a local `.env` file from `.env.example` before running the backend:

```bash
cp .env.example .env
```

For quick local SQLite verification without PostgreSQL:

```powershell
cd backend
$env:DATABASE_URL="sqlite:///./queryshield_local.db"
python -m alembic upgrade head
python -m uvicorn app.main:app --reload
```
